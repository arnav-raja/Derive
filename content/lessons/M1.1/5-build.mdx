## Python as a careful calculator

You will meet Python properly in a later lesson on programs as precise instructions, E1.1. For this lesson you only need it as a calculator that remembers names, and four things are enough:

- `*` multiplies, `/` divides, `+` and `-` add and subtract, and brackets group as usual;
- `3.15e23` is how Python writes $3.15 \times 10^{23}$, and `1e14` is $10^{14}$;
- `name = expression` works out the expression on the right, then gives the result that name so later lines can use it;
- `print(...)` shows values in the output, separated by spaces.

For example, these two lines work out the seconds in a day and then show the result:

```python
seconds_per_day = 24 * 60 * 60
print(seconds_per_day, "seconds in a day")
```

## Compare with the library

You built the conversion yourself, so you know what is inside it. Now check it against a library that knows units. SymPy, a Python library for algebra, can attach a unit to a number and convert between units. A number times a unit, such as `2 * day`, is a quantity, and `convert_to(quantity, unit)` rewrites the quantity in another unit. The first line below brings in the names it needs from SymPy:

```python
from sympy.physics.units import convert_to, second, day

print(convert_to(2 * day, second))   # shows 172800*second
```

SymPy knows several kinds of year. Its `julian_year` is exactly 365.25 days, the year you used. The first run takes a few seconds while SymPy loads.
