## Where this leads

Every later program is built from values, names and expressions, read in exactly this way.

<Foreshadow lesson="E1.2">

A loop runs the same lines again and again, so a line such as `total = total + k` changes `total` on every pass. Reading it needs exactly this lesson's rule: the right side first, with the values as they are now.

</Foreshadow>

<Foreshadow lesson="E1.6">

Text is a value with a type of its own, `str`. E1.6 looks inside it, at the characters, the bytes that store them and the files full of text that programs read.

</Foreshadow>
