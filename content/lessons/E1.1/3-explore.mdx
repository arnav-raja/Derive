## Names refer to values

A program is a list of *statements*, and Python carries them out one at a time, from the top. The puzzle's script is made almost entirely of one kind, the *assignment*, such as `lr = base_lr * batch_size / 256`. An assignment always works in two moves. First Python works out the right side, using the values that the names refer to at that moment. Then it makes the name on the left refer to the result. A name used in this way is called a *variable*.

## Every value has a type

Every value in Python has a *type*, which says what kind of thing it is and so what can be done with it. Four types cover this lesson.

| Type | Holds | Written as |
| --- | --- | --- |
| `int` | a whole number, exactly, however many digits it has | `1024`, `-3`, `0` |
| `float` | a number with a point, to about 16 significant figures | `0.1`, `5.0`, `2.5e-3`, `1e16` |
| `str` | text, a *string* of characters between quotes | `"lr"`, `'1024'` |
| `bool` | a truth value | `True`, `False` |

`2.5e-3` is M1.1's $2.5 \times 10^{-3}$, written the way Python writes it. An `e` always makes a float, even for a whole number, so `1e16` is a float. `type` names the type of any value: `print(type(0.1))` shows `<class 'float'>`. And the type decides what an operation means.

You say which by changing the type yourself, a *conversion*: `int("3")` is the int 3, `float("2.5")` is the float 2.5, and `str(4)` is the string `"4"`. So `int("3") + 4` is 7, and `"3" + str(4)` is `"34"`.

Division is the one place where Python changes a type by itself. `/` always gives a float, even when the division comes out whole: `10 / 2` is `5.0`. ## The order Python works in

Python reads every expression as a tree, as M1.2 did on paper, and it fixes the tree with rules much like the order of operations, called *precedence*. From first to last:

1. anything in brackets;
2. powers, written `**`, so $2^3$ is `2 ** 3`;
3. `*`, `/`, `//` and `%`;
4. `+` and `-`.

At the third and fourth levels a chain is worked from the left, as in M1.2: `20 - 6 - 4` is `(20 - 6) - 4`, which is 10, and `12 / 2 * 3` is `(12 / 2) * 3`, which is `18.0`.

<Reveal for="explore-which-exact">

A float holds exactly the numbers of one form: a whole number of at most 53 binary digits, times a power of two, such as $\frac{5}{8} = 5 \times 2^{-3}$. 0.1 is $\frac{1}{10}$, and $10 = 2 \times 5$, so no power of two in the denominator will do. In binary, $\frac{1}{10}$ goes on for ever, $0.000110011001100\ldots$, just as $\frac{1}{3} = 0.333\ldots$ does in decimal. So Python stores the nearest float instead, $\frac{3{,}602{,}879{,}701{,}896{,}397}{2^{55}}$, which is a little more than 0.1.

53 binary digits are worth about 16 decimal figures, since $2^{53}$ is about $9 \times 10^{15}$. When you print a float, Python shows the shortest decimal that leads back to the same float. That is why `print(0.1)` shows `0.1`, although the float is not exactly 0.1, and why `print(0.1 + 0.2)` shows `0.30000000000000004`: that sum lands on a different float from the one for 0.3.

Whole numbers are floats too, as long as they fit. Every whole number up to $2^{53} = 9{,}007{,}199{,}254{,}740{,}992$ has at most 53 binary digits, so a float holds it exactly. Beyond that, the floats begin to thin out.

<Exercise id="explore-float-gap" />

</Reveal>

<Reveal for="explore-float-gap">

Type `1e16` into the figure: neighbouring floats there are 2 apart. Between $2^{53}$ and $2^{54}$ a whole number has 54 binary digits, one more than a float keeps, so its last binary digit must be 0, and only the even numbers are floats. `1e16 + 1` lies exactly halfway between two floats, and Python rounds it back to `1e16`, so `1e16 + 1 - 1e16` is `0.0`. An int has no such limit: `10 ** 16 + 1` is exactly 10,000,000,000,000,001.

## The names

<Definition term="Value and type">

A *value* is a piece of data that a program works with, such as `1024`, `0.1`, `"lr"` or `True`. Its *type*, such as `int`, `float`, `str` or `bool`, decides what an operation means for it: `+` adds two numbers but joins two strings. Python changes a type only when it is told to, as in `int("42")`, except that `/` always gives a float.

</Definition>

<Definition term="Variable and assignment">

A *variable* is a name that refers to a value. An *assignment* such as `x = x + 1` works out its right side with the values the names refer to at that moment, then makes the name on the left refer to the result. The name keeps the value, never the formula that made it.

</Definition>

<Definition term="Precedence">

The rules that fix an expression's tree: brackets first, then powers, grouped from the right, then a minus sign in front, then `*`, `/`, `//` and `%`, then `+` and `-`, each of the last two levels grouped from the left.

</Definition>

<Definition term="Float">

A number stored as a whole number of at most 53 binary digits times a power of two, good to about 16 significant figures. Any other number, such as 0.1, is stored as the nearest float, so two floats that should be equal may differ in their last digits. Big floats are far apart: near $10^{16}$, 2 apart.

</Definition>
