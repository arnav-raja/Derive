Stepping back can never drop anything but the part of the last character. `errors="ignore"` would give the same answers here, since the only broken character is the one the cut went through, but on bytes from anywhere else it drops whatever is broken without a word, which can hide a bug. A cut between code points can still split what a reader sees as one syllable: `truncate("नमस्ते दुनिया", 10)` keeps स but not the ् that joins it to त. Unicode publishes rules for where the syllables and letters a reader sees begin and end, and text libraries follow them.
