A language model reads a passage as a row of *tokens*, the pieces of text from M1.3's puzzle. In its attention step, each token is compared with itself and with every token before it, but never with a token after it, because when the model writes text the later tokens do not exist yet. Each comparison costs about the same amount of work, so the number of comparisons says how the cost grows with the length of the passage.

A passage of 3 tokens needs $1 + 2 + 3 = 6$ comparisons: the first token is compared only with itself, the second with the first and itself, and the third with all three.

The exact count has an exact answer, and this lesson finds it without adding a thousand numbers one at a time. On the way it gives long sums and long products a short form, a single symbol each.

Long sums come up all over machine learning. An agent that learns by trial and error adds up the rewards it expects, counting each one for less the further away it is, and that sum has no last term at all. It still has a finite total, and this lesson finds it.
