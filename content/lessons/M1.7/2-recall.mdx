This lesson builds on M1.2's equivalent expressions and equations, and on M1.3's functions. Five quick questions check that they are ready. Answer from memory, without a calculator. A miss opens a short re-teach straight away.

<Exercise id="recall-equivalent" />

<Reteach for="recall-equivalent">

<Callback lesson="M1.2">

Two expressions are equivalent when they agree for every value of their letters. Multiplying out and collecting like terms keeps an expression equivalent at every step: $2(x + 3) - x = 2x + 6 - x = x + 6$. A quick check at one value catches a slip, though it cannot prove equivalence: at $x = 1$, $2(1 + 3) - 1 = 7$ and $1 + 6 = 7$.

</Callback>

</Reteach>

<Exercise id="recall-counterexample" />

<Reteach for="recall-counterexample">

<Callback lesson="M1.2">

A claim that two expressions agree for every value is broken by a single value where they differ. At $a = 1$ and $b = 1$, $(a + b)^2 = 4$ but $a^2 + b^2 = 2$, so the two are not equivalent, whatever happens at other values. Agreeing at one value, such as $a = b = 0$, proves nothing, and multiplying out shows the missing term: $(a + b)^2 = a^2 + 2ab + b^2$.

</Callback>

</Reteach>

<Exercise id="recall-solutions" />

<Reteach for="recall-solutions">

<Callback lesson="M1.2">

The solutions of an equation are all the values that make it true. Both $3^2$ and $(-3)^2$ are 9, so $x^2 = 9$ has two solutions, $-3$ and $3$. Taking the square root of both sides gives only the positive one, which is one of the steps M1.2 warned can quietly lose a solution.

</Callback>

</Reteach>

<Exercise id="recall-one-to-one" />

<Reteach for="recall-one-to-one">

<Callback lesson="M1.3">

A function is one-to-one when no two different inputs give the same output, so each output points back to a single input. It is onto when every possible output is reached by some input. And it is a function at all only if every input has exactly one output. The square, $x \mapsto x^2$ on all numbers, is not one-to-one, because $-3$ and $3$ both give 9.

</Callback>

</Reteach>

<Exercise id="recall-def" />

<Reteach for="recall-def">

<Callback lesson="M1.3">

In Python a function is written with `def`, and `return` gives its output. `f(3)` runs the body with `x` standing for 3, so it returns $3 \times 3 - 4 = 5$.

</Callback>
