## Remainders and loops

`n % d` is the remainder when `n` is divided by `d`, so `17 % 5` is 2, and `d` divides `n` exactly when `n % d == 0`. `isqrt(n)`, from Python's `math` module, is the square root of a whole number rounded down to a whole number, so `isqrt(1681)` is 41, and so is `isqrt(1700)`. A program that uses it starts with the line `from math import isqrt`.

A `for` statement runs the lines indented below it once for each value that its `range` gives: `range(a, b)` gives the whole numbers from `a` up to but not including `b`, as in M1.7, so a search that must include a last value ends its range one past it. With one number, `range(b)` starts at 0, so `range(41)` gives 0 to 40, the same as `range(0, 41)`. `if` runs the lines indented below it only when its condition is `True`. A `return` ends the function at once, wherever it is, even inside a loop:

```python
def first_even(a, b):
    for k in range(a, b):
        if k % 2 == 0:
            return k
    return None

print(first_even(7, 12), first_even(7, 8))   # prints 8 None
```

When no `k` in the range passes the test, the loop runs to its end without a `return`, and the last line gives `None`. That `return None` sits level with `for`, after the loop: indented under it, it would end the function after the first `k`.

Here is why it is moved along by one: put $n - 1$ in place of $n$ in $n^2 + n + 41$, and $(n - 1)^2 + (n - 1) + 41 = n^2 - 2n + 1 + n - 1 + 41 = n^2 - n + 41$. ## Hunting for counterexamples

A function can be given to another function as an argument, like any other value, and called inside it:

```python
def twice(f, x):
    return f(f(x))

def add_three(n):
    return n + 3

print(twice(add_three, 10))   # prints 16
```

Checking a proof's claim by machine is a good way to catch a misreading of it, as long as the checks are not mistaken for the proof.

SymPy, the algebra library of M1.2 and M1.3, has faster tools for primes than trial division. `factorint(30031)` gives `{59: 1, 509: 1}`, each prime factor with its power, and `isprime` answers at once for a prime with 40 digits, $10^{39} + 3$, where trial division up to its square root would need more than $3 \times 10^{19}$ divisions, about ten thousand years at a hundred million a second. For numbers below $2^{64}$, about $1.8 \times 10^{19}$, its method is proved always right, by a computer search that covered every number in that range that could fool it: finitely many cases, all checked. For numbers as large as $10^{39} + 3$ it uses a test that has never been known to fail, though experts expect that some number fools it: strong evidence, and not a proof, the very difference this lesson is about.
