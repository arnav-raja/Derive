The puzzle turned on one question: when can a rule be run backwards? To answer it, look first at what a rule is.

## Rules drawn as arrows

Here is a rule that takes a person and gives the month of their birthday, drawn as arrows from people to months.

March has two arrows leaving it, so the turned-round rule is not a function: told "March", it cannot say whose birthday you mean. The trouble began in the first rule, where Asha and Chen share an output. A function in which no two inputs share an output is called *one-to-one*, and only a one-to-one function can be turned round into a function.

## Formulas are rules too

A formula is also a rule. The function $f(x) = x^2$ takes a number and gives its square, so $f(5) = 25$. Here $f$ is the function's name, $x$ stands for its input, and $f(x)$, read "f of x", is its output.

The *graph* of a function has a point $\big(x, f(x)\big)$ for each input $x$: the input is measured across, and its output up. On the graph of $y = x^2$, the two inputs sit at the same height.

Both 3 and $-3$ square to 9, so squaring is not one-to-one, and no rule can recover the input from the output alone: the 9 does not remember the sign that went in. This is the decoder's trouble from the puzzle, in a single formula.

## One rule after another

Functions can be chained, so that the output of one becomes the input of the next.

$f(1) = 4$, and then $g(4) = 8$. The other order gives something else: $f\big(g(1)\big)$ works out $g(1) = 2$ first, and then $f(2) = 5$.

The same steps work with a letter in place of the 1. $f(x) = x + 3$, and $g$ doubles whatever it is given, so $g\big(f(x)\big)$ doubles all of $x + 3$: it is $2(x + 3)$.

In $g\big(f(x)\big) = 2(x + 3) = 2x + 6$ the doubling comes last, so it doubles the 3 as well, while $f\big(g(x)\big) = 2x + 3$ adds the 3 after the doubling. The first is always 3 more than the second, so they are equal for no $x$ at all. Feeding the output of one function into another is called *composition*, and, as with subtraction, the order matters.

Everyday life has the same rule. You put on socks and then shoes, and doing them in the other order gives a different result.

## Undoing a chain

Turning a temperature in Celsius into Fahrenheit is a chain of two steps.

Undo the last step first. Adding 32 came last, so take it off first, then divide by 1.8. For water boiling at 212 °F, $212 - 32 = 180$ and $180 \div 1.8 = 100$ °C. The other order fails: $212 \div 1.8 - 32 \approx 85.8$, not 100. It is socks and shoes again: to undress, the shoes come off first.

Every list decodes to exactly one text, so the decoder is a function. It is not one-to-one, because [0, 1] and [2] share the text `ab`, and that is why decoding cannot always be undone. The encoder runs the other way, from texts to lists.

If some text encoded to [0, 1], decoding [0, 1] would give that text back, so the text would have to be `ab`. But `ab` encodes to [2]. So no text at all encodes to [0, 1]: it is a perfectly good list of ids that the encoder never produces. A function that reaches every possible output is called *onto*, so the encoder is not onto. Here it is on the same texts.

The encoder is one-to-one but not onto: no two texts share a list, but some lists are never reached. Turned round, its arrows would give [0, 1] no output at all, so a function that can be turned round into a function must be onto as well as one-to-one. The decoder is the other way about: onto, since every text comes from some list, but not one-to-one. Decoding undoes encoding, but encoding does not undo decoding, and that was the whole puzzle.

## The names

<Definition term="Function">

A rule that gives every input exactly one output. Its allowed inputs are its *domain*, and the outputs it may give, chosen when the function is set up, are its *codomain*. The output of $f$ at the input $x$ is written $f(x)$.

</Definition>

<Definition term="One-to-one, or injective">

No two inputs share an output: if $f(a) = f(b)$, then $a = b$. The birthday rule and squaring are not one-to-one; doubling and the encoder are.

</Definition>

<Definition term="Onto, or surjective">

Every possible output is reached: for every $y$ in the codomain there is an input $x$ with $f(x) = y$. The decoder is onto; the encoder is not, because nothing reaches [0, 1]. Whether a function is onto depends on the codomain chosen for it: squaring is not onto when every number counts as a possible output, since nothing squares to $-1$, but it is onto when only numbers 0 or more do.

</Definition>

<Definition term="Composition">

Applying $f$ and then $g$ to the result gives a new function, written $g \circ f$ and read "g after f": $(g \circ f)(x) = g\big(f(x)\big)$. The function written nearest to $x$ acts first, and the order usually matters.

</Definition>

<Definition term="Inverse">

A function $g$ undoes $f$ when $g\big(f(x)\big) = x$ for every input $x$. If $f$ also undoes $g$, so that $f\big(g(y)\big) = y$ for every possible output $y$, then $g$ is the inverse of $f$, written $f^{-1}$. The $-1$ is not a power: $f^{-1}(x)$ is not $1/f(x)$.

</Definition>
