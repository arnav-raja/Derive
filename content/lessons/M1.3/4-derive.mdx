## Why only one-to-one functions can be undone

Explore suggested that a function can be undone only when no two inputs share an output. Now prove it. Suppose $f$ has an inverse, and two inputs give the same output.

<Exercise id="derive-inverse-injective" />

</Reveal>

<Reveal for="derive-inverse-injective">

So a function with an inverse is one-to-one. It must also be onto, because $f\big(f^{-1}(y)\big) = y$ says that every possible output $y$ is reached, from the input $f^{-1}(y)$.

The converse holds too. If $f$ is one-to-one and onto, every possible output comes from exactly one input, and the rule that sends each output back to that input is an inverse. A function that is both one-to-one and onto is called *bijective*, so a function has an inverse exactly when it is bijective.

## Undoing a chain, in reverse order

In Explore you undid Celsius to Fahrenheit by undoing the last step first. Here is why that always works. Take two functions $f$ and $g$ that both have inverses. The chain $g \circ f$ applies $f$ first and then $g$. The claim is that $f^{-1} \circ g^{-1}$, which undoes $g$ first and then $f$, is its inverse.

<Exercise id="derive-socks-shoes" />

</Reveal>

<Reveal for="derive-socks-shoes">

So $f^{-1} \circ g^{-1}$ undoes $g \circ f$. The same steps, with $g\big(g^{-1}(u)\big) = u$ and $f\big(f^{-1}(u)\big) = u$ in place of the undo rules, show that $g \circ f$ undoes $f^{-1} \circ g^{-1}$ as well, so it is the inverse:

$$
(g \circ f)^{-1} = f^{-1} \circ g^{-1}.
$$

The inverse of a chain undoes its steps in reverse order. Socks, then shoes; to undo them, shoes, then socks.

## Making a function one-to-one

Squaring is not one-to-one, so on all numbers it has no inverse. The square root looks as if it should be one.

<Exercise id="derive-root-square" />

</Reveal>

<Reveal for="derive-root-square">

$(-3)^2 = 9$, and $\sqrt{9} = 3$, because $\sqrt{y}$ always means the number that is 0 or more whose square is $y$. The square root sent back 3, not the $-3$ that went in. So $\sqrt{x^2} = x$ only when $x \ge 0$; when $x$ is negative, $\sqrt{x^2} = -x$. Both cases together say $\sqrt{x^2} = |x|$, the size of $x$ ignoring its sign.

In M1.1, on quantities and units, a square root undid a square: $\sqrt{9} = 3$, because $3^2 = 9$. It does, but only for numbers that are 0 or more. The cure is to narrow the function. Allow only inputs $x \ge 0$, and count only numbers 0 or more as possible outputs. Then no two inputs share a square, and every such $y$ is the square of $\sqrt{y}$, so squaring is one-to-one and onto, and the square root is its inverse. Narrowing the inputs of a function in this way is called *restricting its domain*.

<Exercise id="derive-restrict-inverse" />

</Reveal>

<Reveal for="derive-restrict-inverse">

<Steps>
  <Step why="the rule, for inputs x ≥ 2">$y = (x - 2)^2$</Step>
  <Step why="take square roots: x − 2 is 0 or more, so it is the root itself">$\sqrt{y} = x - 2$</Step>
  <Step why="add 2 to both sides">$\sqrt{y} + 2 = x$</Step>
</Steps>

The narrowing did real work in the second line. Without it, $x - 2$ could be negative and equal to $-\sqrt{y}$, and then $x = 2 - \sqrt{y}$ would fit just as well: two inputs again, and no inverse. Taking the square root of both sides of an equation is safe only when you know the sign of what is being squared.

## A second angle: the graph

A graph shows each input paired with its output. See what an inverse does to a graph.

The square root takes 4 back to 2, so $(4, 2)$ is on the graph of $y = \sqrt{x}$: the same two numbers as $(2, 4)$, swapped. The same happens to every point. Each point $(a, b)$ on the graph of a function becomes the point $(b, a)$ on the graph of its inverse, because input and output change places.

Folding the picture along the line $y = x$ swaps the two axes, so it carries every point $(a, b)$ to $(b, a)$. The graph of an inverse is therefore the mirror image of the graph of the function in the line $y = x$, which the picture shows because both axes have the same scale.

The mirror also gives a test you can see. A function is one-to-one exactly when no horizontal line crosses its graph more than once, and then its mirror image is again the graph of a function. A horizontal line at height 9 crosses the full graph of $y = x^2$ twice, at $x = -3$ and $x = 3$.
