## Functions in Python

In Python a function is written with `def`. Here is one, and a call of it:

```python
def double(x):
    return 2 * x

print(double(21))   # prints 42
```

The name after `def` names the function, and `x` stands for its input. The first line ends with a colon, and the indented lines under it are the function's *body*, the steps it carries out; the body ends where the indenting stops. `return` gives the output. Like a mathematical function, a Python function can be any rule at all, not only a formula. A function and its inverse are two such definitions.

## Compare with the library

SymPy can find an inverse by solving an equation exactly. `Eq(left, right)` builds an equation, and `solve(equation, x)` gives the list of every value of `x` that makes it true. SymPy takes a few seconds to load the first time you run it.

```python
from sympy import symbols, Eq, solve

x = symbols("x")
print(solve(Eq(3*x + 2, 17), x))   # prints [5]
```

For the chain, SymPy gives one solution, $\tfrac{y}{2} - 3$: halve first, undoing the doubling that was done last, and then take off the 3. That is $f^{-1} \circ g^{-1}$ from Derive, found by the machine. For the square it gives two, $-\sqrt{y}$ and $\sqrt{y}$: the square cannot be undone without knowing the sign, which is this lesson in one line of output. For these two equations, a list holding one solution means the input can be recovered from the output, and a list holding two means it cannot be, not without more information. SymPy reached each answer by exact algebra on the letters, not by trying a few values.
