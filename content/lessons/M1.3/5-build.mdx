## Functions in Python

In Python a function is written with `def`. Here is one, and a call of it:

```python
def double(x):
    return 2 * x

print(double(21))   # prints 42
```

The name after `def` names the function, `x` stands for its input, and `return` gives its output. Like a mathematical function, a Python function can be any rule at all, not only a formula. A function and its inverse are two such definitions.

## Chaining in the right order

Scientists measure temperature in kelvin, which starts from absolute zero, the coldest anything can be: a temperature of $C$ degrees Celsius is $C + 273.15$ kelvin, written K. To turn kelvin into Fahrenheit, go by way of Celsius: first kelvin to Celsius, then Celsius to Fahrenheit. In Python, as in $g\big(f(x)\big)$, the inner call runs first.

## Compare with the library

SymPy can find an inverse by solving an equation exactly. `Eq(left, right)` builds an equation, and `solve(equation, x)` gives the list of every value of `x` that makes it true. SymPy takes a few seconds to load the first time you run it.

```python
from sympy import symbols, Eq, solve

x = symbols("x")
print(solve(Eq(3*x + 2, 17), x))   # prints [5]
```

A list holding one formula means the input can be recovered from the output. A list holding two means it cannot be, not without more information.
