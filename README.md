# Derive

A private, Feynman-inspired school for the mathematics, machine learning and ML engineering used
at frontier AI labs. One learner, three curriculums, 332 long-arc lessons and nine capstones,
joined into one prerequisite graph.

Each lesson runs six phases: Puzzle, Recall, Explore, Derive, Build, and Explain and connect.
Practice runs in the browser (Python through Pyodide, maths checked with SymPy), reviews are
scheduled with FSRS, and a tutor built on the Claude API gives hints on a five-rung ladder and
never a solution.

GitHub Actions builds it and publishes the site to GitHub Pages, at
https://arnav-raja.github.io/Derive/, with its server (pages, progress and the tutor) running as
a Supabase Edge Function.

See `CLAUDE.md` for how the project is built and `docs/STATUS.md` for where it stands.
